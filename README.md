# 鹿练 LuLian

鹿角虫的健身记录。手机优先，浅色底与鹿绿色，记录每一组，参考上次表现。

## 本地运行

使用 Node.js 24，首次运行安装依赖：

```powershell
cd D:\Pythontest\LuLian
npm install
npm run dev
```

电脑打开 http://localhost:5173 。小米手机与电脑连接同一局域网，用手机自带浏览器打开终端打印的 `Network` 地址，例如 `http://192.168.1.10:5173`。电脑需要保持服务运行；若访问不到，检查是否同网及系统防火墙是否允许 Node.js 的局域网访问。

开发端口固定为 5173；占用时会报错，避免自动换端口导致进入另一份浏览器存储。局域网地址用于本地开发。

网页地址：[打开鹿练](https://lulian-lvjunchi.myworkspace-3144.chatgpt.site)。

网页使用 Sites 托管，链接可直接访问、无需登录，发布后无需电脑保持运行。静态目录为 `dist/`，站点标识保存在 `.openai/hosting.json`。源码维护在 [GitHub](https://github.com/lvjunchi/LuLian)；推送 GitHub 不会自动发布网站，更新后需重新构建并发布 Sites 版本。

线上地址和本地开发地址的浏览器数据相互独立。如需迁移已记录的训练，请先在旧地址导出 JSON，再在新地址导入。

## 首版功能

- 训练：自由训练、从模板或历史开始；逐组重量与次数、热身组、完成状态、动作和训练备注。
- 快速操作：上次表现、带入上次、复制上一组、增减组、动作替换与排序、组间休息计时。
- 模板：自定义动作与目标组，提供三份可编辑的起点；模板修改不会改写历史。
- 有氧：运动类型、分钟、可选距离；从历史复用时保留类型，实际时长和距离重新填写。
- 历史：月历、训练详情、补记、修改、删除、复用和存为力量模板。
- 统计：本周次数、正式训练容量、动作重量或次数趋势、体重趋势；动作图表和列表可返回原始记录。
- 数据：IndexedDB 自动保存训练草稿，完整 JSON 备份与恢复，逐组 CSV 分析导出。

## 记录与保存规则

- 预填不等于完成，开始新训练时所有组均重置为未完成。修改已完成组的数字后，需要重新勾选。
- 重量单位为 kg。哑铃按单只重量、杠铃按总重量记录；自重只统计次数，辅助重量单独处理。
- 正式容量 = 外部负重动作中已完成正式组的重量 × 次数之和；不计热身、自重和辅助组。哑铃容量按记录的单只重量计算。
- 未完成组保留在历史和 CSV 中，不计入容量。统计直接根据历史计算，编辑后立即更新。
- 保存失败会明确提示，页面中的数据仍可导出；多页面编辑冲突会阻止旧页面覆盖较新的记录，请先备份再重新打开。
- 休息计时依据结束时间恢复。后台、锁屏时不承诺通知或响铃，返回页面可以查看剩余时间。

## 备份和恢复

在右上角设置中下载完整 JSON。文件包含历史、模板、自定义动作、体重、草稿和设置；CSV 用于分析，不用于恢复。

恢复前校验格式、版本、字段和动作引用；无效文件不会替换数据。有效备份采用整体替换，先下载当前数据的备份，确认文件已由浏览器保存后，再点击恢复。若本机数据无法读取，启动页面也提供从文件恢复的入口。

数据归属于**当前浏览器和网站地址（协议、主机、端口）**。电脑 localhost 与手机局域网地址不共享数据；更换浏览器、地址或清理网站数据前，请先导出备份。浏览器本地保存不是云端备份。

## 检查和构建

```powershell
npm test
npm run build
```

测试覆盖完成状态、容量口径、历史引用、模板隔离、备份校验、CSV 转义、草稿保存、连续写入与多页面冲突。IndexedDB 测试使用开发依赖 fake-indexeddb；运行时依赖只有 React 和 React DOM。生产静态文件输出到 `dist/`。

小米手机实机验收：

1. 自由训练添加动作，填一组重量和次数，勾选完成，检查休息计时。
2. 点击下一组的 `↳` 复制，确认数字带入但未自动完成；点击组号切换热身/正式。
3. 刷新或退出后重新打开，确认草稿、已完成状态和剩余休息时间恢复。
4. 结束训练，从历史编辑数据，确认统计同步；再练一次，确认组的完成状态重置。
5. 下载 JSON，在另一浏览器或另一网站地址导入，核对模板、历史和体重；确认损坏的文件不能覆盖原数据。
6. 输入时检查数字键盘、页面宽度、弹窗滚动及下载文件，确保主要操作可触及。
